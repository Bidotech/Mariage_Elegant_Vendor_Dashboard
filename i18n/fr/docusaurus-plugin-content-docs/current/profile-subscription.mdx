# Profil et abonnement

## Profil

Utilisez **Profil** pour ajouter le nom et le numéro de téléphone utilisés dans les communications avec l’administrateur. Ces coordonnées administratives ne sont pas visibles par les autres utilisateurs.

## Choisir un abonnement

La section **Abonnement** permet de maintenir votre fiche fournisseur visible sur la plateforme. Les forfaits présentés dans le tableau de bord comprennent :

- **RADIANCE** — six mois; et
- **ETERNAL SHINE** — un an.

Vous pouvez acheter un forfait en ligne ou communiquer avec l’administrateur pour organiser un paiement manuel.

## Factures et historique

Après le paiement, prévoyez quelques heures avant que la facture apparaisse. L’historique présente la date d’achat, la date d’expiration, le prix, l’utilisateur et la facture PDF disponible.

Utilisez **Upgrade plan** pour changer de forfait. Vérifiez les conséquences avant de sélectionner **Cancel subscription**.
